Kid Tutor wireframes

Low-fidelity sketches at 13-inch iPad size. Click a screen to open it, then use the links under each screen to walk the flow. Notes beside each screen say what the app speaks and how it behaves.

Design principles How we work Simulator screenshots

Session flow

Home→ Writing letters→ Writing words→ Spelling→ Vocab→ Puzzles→ …→ Session done→ Home→ Rewards→ Toy chest

Screens

Child home Draft

Six subject tiles (including a mixed “bit of everything”), settings gear top right.
Writing: letters Built

Copy a letter three times: trace, then copy, then from memory.
Writing: words Built

Copy a shown word letter by letter; later look, cover, write.
Spelling Built

The word with missing letters; the child writes in the yellow boxes.
Reading Built

Read a word aloud; on-device speech recognition checks it.
Math Built

A number fact; the answer is written in digit boxes, with counting dots as help.
Vocab Draft

Hear a word, tap pictures to hear their meanings, pick one.
Puzzles: what comes next? Built

A row with a gap at the end; tap the tile that continues the pattern.
Puzzles: odd one out Built

Four tiles, three go together; tap the one that doesn't belong.
Puzzles: finish the grid Built

Rows and columns each follow a rule; tap the tile that fills the gap.
Puzzles: who am I? Built

Spoken clues, shown as picture chips; tap the only tile that fits them all.
Session done Draft

Specific praise, a new sticker, and milestone progress.
Rewards: claw machine Built

Spend a token, aim the claw, drop on a pile of squishy toys. Off-center grabs slip out; misses improve the grip.
Toy chest Built

Shelves of won toys; tap one to hear its name.
Progress Built

In Settings: each subject's deck, with how many cards are learned, in progress and to do.
Parent dashboard Draft

This week's practice, what needs attention, and rewards.
